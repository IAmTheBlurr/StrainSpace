# Success Metrics

## Mathematical correctness

- exact D6 projections match exhaustive enumeration
- threshold boundaries change only where specified
- pair-strain functions satisfy documented invariants
- seeded counter-profile closes the expected hole
- property tests cover monotonicity and symmetry where applicable

## Product clarity

- a new viewer identifies the structural hole within thirty seconds
- a new viewer can explain the projection stack after one guided interaction
- each visual element maps to a defined mathematical object

## Model reliability

- every compiled rule passes schema validation
- invalid rules fail safely
- every numerical explanation claim maps to computed evidence
- no model-generated arithmetic enters saved results

## Hackathon readiness

- clean install and run path
- public demonstration under three minutes
- repository contains no protected names or copied rules prose
- provenance separates pre-existing research from Build Week implementation
- primary Codex thread produces a valid `/feedback` Session ID

## Research value

- hole definition remains explicit and falsifiable
- counterfactual repair changes computed coverage as predicted
- representation adds diagnostic value beyond average damage alone
