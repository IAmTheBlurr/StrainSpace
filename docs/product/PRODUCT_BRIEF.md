# Product Brief

## Product name

StrainSpace

## One-sentence description

StrainSpace reveals structural force-list weaknesses by projecting relational profile geometry into finite dice and effect spaces.

## User problem

Tabletop players often evaluate forces through isolated profile values, average damage, received wisdom, or sparse win-rate data. Those methods hide relational thresholds, role coverage, redundancy, and matchup-specific holes.

## Proposed solution

StrainSpace accepts two generic force lists and computes pairwise relations across attack and defense profiles. It exposes threshold regions, finite D6 subsets, projected effects, coverage, and missing responses through an interactive visual interface.

## Primary user

A serious tabletop player who wants stronger list construction, matchup preparation, and post-game diagnosis.

## Hackathon use case

A user loads two proxy forces. The coverage matrix reveals one heavy-defense region with no efficient friendly response. A profile substitution crosses a threshold boundary, expands the successful dice subset, and closes the hole. GPT-5.6 explains the result using deterministic evidence.

## Core value

- Replace flat aggregate ratings with relational structure.
- Show why a profile succeeds or fails.
- Identify missing capability before play.
- Compare counterfactual list changes.
- Preserve mathematical auditability.

## Product promise

The application will answer four questions:

1. Which opposing regions can my force address?
2. Where does my force lack an adequate response?
3. Which threshold causes the weakness?
4. Which minimal profile change closes the weakness?

## Differentiation

Most tabletop calculators answer expected-damage questions for one interaction. StrainSpace maps many interactions as a geometric coverage system and identifies structural holes across a complete pair of lists.

## Model role

GPT-5.6 provides constrained rule compilation and evidence-grounded explanation. Deterministic code computes all mathematical results.

## Long-term direction

Future versions can add post-game diagnosis, spatial reachability, mission-conditioned capability, victory-point envelopes, and policy-aware board-state projections.
