# Build Week Checklist

## Repository

- [ ] public repository or required judge access
- [ ] pre-existing research separated from new implementation
- [ ] clean commit history
- [ ] install and run instructions
- [ ] license status explicit
- [ ] no secrets
- [ ] no protected names or copied prose

## Codex

- [ ] primary Codex thread selected
- [ ] core implementation occurs in the primary thread
- [ ] plugins installed as needed
- [ ] new session opened after plugin installation when required
- [ ] `/feedback` Session ID captured
- [ ] provenance log names major Codex contributions

## Product

- [ ] two proxy fixtures load
- [ ] exact D6 engine passes
- [ ] coverage matrix works
- [ ] seeded absolute hole appears
- [ ] efficiency hole appears
- [ ] counterfactual closes a hole
- [ ] GPT-5.6 compiles one constrained rule
- [ ] GPT-5.6 explanation cites deterministic evidence
- [ ] interface handles loading, empty, error, and success states

## Demo

- [ ] video under three minutes
- [ ] public YouTube URL
- [ ] voiceover included
- [ ] problem visible within twenty seconds
- [ ] geometric projection visible
- [ ] hole visible
- [ ] repair visible
- [ ] Codex and GPT-5.6 roles visible
- [ ] no third-party protected media

## Submission

- [ ] project description
- [ ] judging track selected
- [ ] repository URL
- [ ] deployed or locally testable build
- [ ] screenshots
- [ ] video URL
- [ ] Codex Session ID
- [ ] third-party materials disclosure
- [ ] final deadline verified on official page
