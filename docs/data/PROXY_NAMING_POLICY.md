# Proxy Naming Policy

## Goal

Create a self-contained tabletop analysis domain with no dependence on source-game recognition.

## Naming rules

- Use original faction names.
- Use original entity names.
- Use original profile names.
- Use original ability names.
- Use functional field labels drawn from general game design language.
- Avoid phonetic jokes, near-spellings, lore references, visual mimicry, and distinctive slogans.

## Recommended field vocabulary

| Concept | Proxy label |
|---|---|
| movement | mobility |
| toughness | resilience |
| save | protection threshold |
| wounds | health |
| objective control | control |
| ballistic or weapon skill | accuracy threshold |
| strength | power |
| armor penetration | penetration |
| damage | damage |
| attacks | count |

## Naming style

Use neutral science-fiction, abstract, or geometric naming systems created for StrainSpace.

Examples:

- Proxy Faction Alpha: Meridian Compact
- Proxy Faction Beta: Vesper Array
- Entity IDs: Meridian Frame 01, Vesper Node 03
- Profiles: Focused Pulse, Fracture Arc, Dense Impact

These names are placeholders. Run a trademark search before public branding or commercialization.

## Automated review

Maintain a forbidden-term list outside public output and run a case-insensitive scan across:

- tracked fixtures
- UI text
- tests
- screenshots
- captions
- demo script
- generated explanations
